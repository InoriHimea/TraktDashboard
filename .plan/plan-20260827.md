# Plan 2026-08-27 — 本地账号登录

## 背景

Trakt OAuth 需要用户自行创建应用凭据，当前环境暂时无法完成 Trakt 登录。系统需要先提供不依赖 Trakt 的本地账号登录能力，保证用户可以进入自托管实例并继续使用本地功能；Trakt/Jellyfin 数据同步作为后续独立决策，不在本批实现。

## 实现范围

- [x] `users` 增加可选的 `local_username` 和 `local_password_hash` 字段。
- [x] Trakt token 与过期时间字段改为 nullable，允许没有外部账号的本地用户。
- [x] 新增幂等数据库迁移 `0019_local_auth.sql`、journal 注册和 `runMigrations()` 补偿 DDL。
- [x] 使用 Node 内置 `scrypt` + 随机 salt 哈希和校验密码，避免引入原生依赖。
- [x] 新增 `POST /auth/local/register` 和 `POST /auth/local/login`，使用现有 JWT session cookie。
- [x] 注册限制为单用户实例一个本地账号；已有 Trakt 用户可补充本地凭据。
- [x] Trakt client 对无 token 用户返回明确的未连接错误，不尝试解密 null。
- [x] 前端登录页增加本地登录/注册表单和错误提示，保留 Trakt OAuth 入口。
- [x] 补充 API 与 web 测试。

## 非范围

- Jellyfin 观看历史同步。
- Trakt token 申请、Trakt 数据同步重构。
- 多用户权限模型。

## 验收标准

- 本地账号可以注册、设置 session cookie，并通过登录验证进入 `/tv-shows`。
- 密码不以明文存储，错误凭据返回通用认证错误。
- 没有 Trakt token 的用户不会在 token 解密处崩溃；Trakt 功能返回未连接错误。
- API 与 web 的 TypeScript、lint 和测试通过。
